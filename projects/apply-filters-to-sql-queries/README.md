# Apply Filters to SQL Queries

An educational project from the Google Cybersecurity Certificate demonstrating how SQL filters can help retrieve relevant records during a security investigation.

## Project overview

In this simulated training exercise, I investigated potential security issues by querying the `log_in_attempts` and `employees` tables. I used `SELECT` and `FROM` to retrieve records, then applied `WHERE` conditions and logical operators to narrow the results.

## Queries completed

The project documents six filtering tasks:

1. Find failed login attempts made after 18:00 using `success = 0` and `login_time > '18:00'`.
2. Retrieve login attempts from two specified dates using `OR`.
3. Find login attempts originating outside Mexico using `NOT` and `LIKE`.
4. Find employees in Marketing offices whose office value begins with `East` using `AND` and `LIKE`.
5. Retrieve employees in either Sales or Finance using `OR`.
6. Retrieve employees outside Information Technology using `NOT`.

## Skills demonstrated

- Querying structured records with SQL `SELECT`, `FROM`, and `WHERE`
- Combining conditions with `AND`, `OR`, and `NOT`
- Matching text patterns with `LIKE` and the `%` wildcard
- Filtering login and employee records for investigation questions
- Explaining how query conditions affect returned records

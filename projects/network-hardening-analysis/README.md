# Network Hardening Analysis

A security risk assessment completed as part of the Google Cybersecurity Certificate on Coursera, for the activity **Analysis of network hardening**.

## Scenario

A fictional social media organisation experienced a data breach affecting customer information. The supplied scenario identified shared employee passwords, a default database administrator password, missing firewall traffic-filtering rules, and no multifactor authentication.

## My assessment

I selected three hardening methods:

- **Firewall rules:** allow required traffic and block unauthorised inbound and outbound traffic. Rules filter continuously and should be reviewed periodically and when network requirements change.
- **Network access privileges:** limit access according to roles and responsibilities using the principle of least privilege.
- **Multifactor authentication (MFA):** require different authentication factors so a password alone is insufficient to gain access.

The report explains how firewall filtering and MFA reduce the risk of future unauthorised access.
